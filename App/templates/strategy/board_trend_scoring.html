板块趋势打分

将板块周期划分为 上涨前期 / 上涨后期 / 下跌前期 / 下跌后期，多维度评估趋势区间。打分公式后续接入。

🗂 板块数据管理

字段说明 & 计算公式（v1）

数据源：data_stock_daily（首选）/ datadaily.{board_code}（回退） · 计算窗口：最近 250 个交易日

阶段 trend_stage

结合 DIF 是否在零轴上、价格相对 MA20、MA20 5 日斜率综合判定。

  • up_early 上涨前期：DIF<0 但 close>MA20 且柱体上行（反弹/筑底突破）；或零轴上方多头排列尚不极端
  • up_late 上涨后期：零轴上方且 RSI≥70 或 60日位置≥90；或 close>MA20 但 MA20 走平/下行（顶部钝化）
  • down_early 下跌前期：close 跌破 MA20 但 DIF 还在零轴上方；或零轴下方 MA20 上行
  • down_late 下跌后期：DIF<0、close<MA20 且 MA20 走平/下行（趋势性下跌）
  • unknown：数据不足（少于 20 根日 K）

置信度 trend_stage_confidence (0–100)

各子分相对中性线 50 的方向一致性。

对 5 个核心子分（均线/MACD/量能/动量/价格结构）逐一打分：
  ≥50 记 +1，否则 -1
confidence = |Σ signs| / 5 × 100

全部 5 项一致看多或一致看空 → 100；3 多 2 空 → 20；五五开 → 0。

强度 trend_strength

仅由综合分映射：

total ≥ 75 → strong（强）
total ≥ 60 → medium（中）
total ≥ 40 → weak（弱）
total < 40 → none（无趋势）

信号 signal

up_early   → buy
up_late    → hold（RSI<75）/ sell（RSI≥75）
down_early → sell
down_late  → wait

注意：信号仅供参考，结合实际仓位与风险敞口决策。

价格结构 price_structure_score（权重 15%）

pos = (close - low60) / (high60 - low60) × 100
+5 若创 20 日新高，-5 若创 20 日新低
score = clip(pos, 0, 100)

含义：当前价在近 60 日区间中所处的位置。

均线 ma_score（权重 20%）

cur > MA20 > MA60 → 80（MA20 斜率向上 → 95）
MA20 > MA60          → 65
cur > MA20 但 MA20<MA60 → 55
cur < MA20 < MA60     → 20（MA20 斜率向下 → 5）
其他                  → 35

slope20 = (MA20[今] - MA20[前 5 日]) / |MA20[前 5 日]| × 100。

MACD macd_score（权重 25%）

EMA12, EMA26 → DIF = EMA12 - EMA26
DEA = EMA9(DIF)，柱体 BAR = 2(DIF - DEA)
dif_score = linmap(DIF/close × 100, -2 → 0, +2 → 100)
bar_score = 65 若柱体向上, 35 若向下
   DIF>0 且 DEA>0 → +15；同负 → -15
score = 0.55 × dif_score + 0.45 × bar_score

量能 volume_score（权重 15%）

v5  = mean(volume, 最近 5 日)
v60 = mean(volume, 最近 60 日)
ratio = v5 / v60
score = linmap(ratio, 0.5 → 0, 2.0 → 100)

含义：放量/缩量。比值 1.5 ≈ 90 分；1.0 ≈ 60 分；0.5 ≈ 30 分。

动量 momentum_score（权重 15%）

RSI(14)：
 50–65 → 80–95（健康看多）
 65–85 → 80→50（越超买越扣）
 40–50 → 50→75
 20–40 → 30→50

波动率 volatility_score（权重 10%）

ATR(14) = mean(TR, 14)
atr_pct = ATR / close × 100
< 1%   → 30–60（无行情）
1–3%   → 60–90（理想）
3–5%   → 90–60
> 5%   → 60–25（风险高）

综合分 total_score

total = (15·价格结构 + 20·均线 + 25·MACD + 15·量能 + 15·动量 + 10·波动率) / 100

权重总和 100，全部子分 0–100 同向（高 = 看多有利），因此 total 也保持 0–100，60 以上为偏多区。
