# A股行情数据接口清单（免费·免token）

> 从实盘复盘工具里抽出来的一线可用接口。全部是新浪/腾讯/东方财富/同花顺的公开 HTTP 接口，**不需要注册、不需要 API key**。
> 三个共性坑，先记住：
> 1. **Referer 头必须带**（新浪/东财会校验，否则 403 或空）。
> 2. **新浪/腾讯返回是 GBK 编码**，PHP 里要 `mb_convert_encoding($resp,'UTF-8','GBK')`，否则中文乱码 / json 失败。
> 3. **东财搜索接口返回 JSONP**（`jQuery123({...})`），要先用正则剥掉回调外壳再 `json_decode`。
> 代码 `symbol` 规则：`6` 开头是沪市 → `sh` 前缀；其余（0/3/000…）是深市 → `sz` 前缀。东财 `secid` 规则：沪 `1.代码`，深 `0.代码`。

---

## 1. 新浪 · 历史K线（分时/日K）★最常用
```
GET https://quotes.sina.cn/cn/api/json_v2.php/CN_MarketDataService.getKLineData
    ?symbol=sh600000&scale=5&ma=no&datalen=480
Header: Referer: https://finance.sina.com.cn/
```
- `scale`：K线周期分钟数。`5`=5分钟（画分时/盘中），`240`=日K，`60`=60分钟。
- `datalen`：返回多少根（最大约 2400）。5分钟一天 48 根。
- 返回：JSON 数组，每根 `{day, open, high, low, close, volume}`，`day` 形如 `2024-01-02 09:35:00`。
- 用途：分时走势图、历史涨跌幅、判断次新股（日K不足260根=上市不满一年，最早一根即上市日）。

## 2. 新浪 · 实时行情（批量）
```
GET https://hq.sinajs.cn/list=sh600000,sz000001,sh601318
Header: Referer: https://finance.sina.com.cn/    ← 不带必 403
```
- 一次可查上百只，逗号分隔；URL 别太长，建议每批 ≤140 只。
- 返回 GBK 文本：`var hq_str_sh600000="浦发银行,开,昨收,现价,高,低,...";`，逐行正则 `hq_str_(\w+)="(.*)"` 再按 `,` 拆字段。
- 字段：`[0]`名称 `[1]`今开 `[2]`昨收 `[3]`现价 `[4]`最高 `[5]`最低 `[8]`成交量 `[9]`成交额 `[30]`日期 `[31]`时间。

## 3. 腾讯 · 实时行情（含市值/市盈率）★直连最稳
```
GET https://qt.gtimg.cn/q=sh600000
Header: Referer: https://gu.qq.com/
```
- 返回 GBK：`v_sh600000="1~浦发银行~600000~现价~...";`，取 `="(.*)"` 再按 `~` 拆。
- 关键字段：`[1]`名称 `[3]`现价 `[39]`市盈率TTM（<0 即亏损） `[44]`流通市值(亿) `[45]`总市值(亿)。
- 相比新浪，市值/PE 字段更全，适合基本面快照。

## 4. 东方财富 · 股票联想搜索（名称↔代码）
```
GET https://searchadapter.eastmoney.com/api/suggest/get?input=浦发&type=14&count=12
Header: Referer: https://www.eastmoney.com/
```
- 返回 **JSONP**，先 `preg_replace` 剥壳。数据在 `QuotationCodeTable.Data[]`，字段 `Code/Name/PinYin/Classify`（`Classify=='AStock'` 才是沪深A股）。
- 用途：把用户输入的名字/拼音解析成 6 位代码。（注：直连有时返回陈旧缓存，最好本地维护一张全量股票表兜底，见接口 8。）

## 5. 东方财富 · 龙虎榜明细
```
GET https://datacenter-web.eastmoney.com/api/data/v1/get
    ?reportName=RPT_DAILYBILLBOARD_DETAILSNEW&columns=ALL&source=WEB&client=WEB
    &sortColumns=TRADE_DATE,SECURITY_CODE&sortTypes=1,1
    &pageSize=500&pageNumber=1
    &filter=(TRADE_DATE>='2024-01-01')(TRADE_DATE<='2024-01-31')
Header: Referer: https://data.eastmoney.com/
```
- 数据在 `result.data[]`，总页数 `result.pages`。单页最大 500，多了也只返回 500，需翻页。
- 这是东财的通用 datacenter 接口，换 `reportName` 可拉几百种榜单（资金流、业绩预告等），套路一样。

## 6. 东方财富 · 涨停池 / 炸板池
```
GET https://push2ex.eastmoney.com/getTopicZTPool   ← 涨停池
GET https://push2ex.eastmoney.com/getTopicZBPool   ← 炸板池
    ?ut=7eea3edcaed734bea9cbfc24409ed989&dpt=wz.ztzt&Pageindex=0&pagesize=500&date=20240102
Header: Referer: https://quote.eastmoney.com/
```
- 数据在 `data.pool[]`。常用字段：`c`代码 `n`名称 `zdp`涨跌幅 `lbc`连板数 `zbc`炸板次数 `fbt`首封时间(HHMMSS) `hybk`行业板块 `fund`封单额 `zttj.days`几天几板。
- 是**当前时刻快照**，收盘后再拉即为当日最终结果。

## 7. 东方财富 · 盘口异动（涨停/炸板/大买盘实时）
```
GET https://push2ex.eastmoney.com/getAllStockChanges
    ?type=8201,8202,8193,4,8205,8194,8203,8204
    &ut=7eea3edcaed734bea9cbfc24409ed989&pageindex=0&pagesize=64&dpt=wzchanges
Header: Referer: https://quote.eastmoney.com/
```
- 数据在 `data.allstock[]`，`t`=异动类型码：`8201`封涨停 `8202`炸板 `8193`火箭发射 `4`大笔买入 `8205`有大买盘 `8194`高台跳水 `8203`封跌停 `8204`跌停打开。
- 用途：盘中监控资金异动。

## 8. 东方财富 · 全市场清单 + 行业归属
```
GET https://push2.eastmoney.com/api/qt/clist/get
    ?pn=1&pz=100&po=0&np=1&fltt=2&invt=2&fid=f12
    &fs=m:0+t:6,m:0+t:80,m:1+t:2,m:1+t:23,m:0+t:81+s:2048
    &fields=f12,f14,f100
Header: Referer: https://quote.eastmoney.com/
```
- 数据在 `data.diff[]`，`f12`代码 `f14`名称 `f100`所属行业。总数 `data.total`，每页 100，全市场约 59 页。
- `fs` 是市场板块筛选串（上面这串=沪深全部A股）；`fid` 排序字段，**按代码 f12 排序翻页**（按涨跌幅排会因行情变动漏抓/重复）。
- 用途：一次性同步全量股票表（本地兜底搜索、名称→代码映射），比接口4靠谱。

## 9. 东方财富 · 7×24 快讯
```
GET https://np-listapi.eastmoney.com/comm/web/getFastNewsList
    ?client=web&biz=web_724&fastColumn=102&sortEnd=&pageSize=100&req_trace=1
Header: Referer: https://kuaixun.eastmoney.com/
```
- 数据在 `data.fastNewsList[]`。用途：题材催化/消息面监控。

## 10. 同花顺 · 涨停原因 / 题材板块
```
GET https://data.10jqka.com.cn/dataapi/limit_up/<path>
Header: Referer: https://data.10jqka.com.cn/
UA:     完整浏览器 UA（Mozilla/5.0 … Chrome/120 …）
```
- `<path>` 例：`block_top?...`（按“涨停原因”聚合的题材板块，如机器人/储能/DeepSeek 每天为什么涨）。
- 注意：**必须带 `Accept-Encoding` 支持 gzip**（curl 里设 `CURLOPT_ENCODING=''` 让 curl 自动解压），否则拿到乱码。

## 通用调用模板（PHP / curl）
```php
function fetch($url, $referer, $gbk = false) {
    $ch = curl_init($url);
    curl_setopt_array($ch, [
        CURLOPT_RETURNTRANSFER => 1,
        CURLOPT_SSL_VERIFYPEER => 0,
        CURLOPT_TIMEOUT        => 8,
        CURLOPT_ENCODING       => '',            // 自动 gzip 解压（同花顺必须）
        CURLOPT_HTTPHEADER     => ["Referer: $referer", 'User-Agent: Mozilla/5.0'],
    ]);
    $resp = curl_exec($ch);
    curl_close($ch);
    if ($resp !== false && $gbk) $resp = mb_convert_encoding($resp, 'UTF-8', 'GBK');
    return $resp;
}
// 剥 JSONP 外壳（东财 suggest 用）
function strip_jsonp($s) {
    $s = trim($s);
    return preg_match('/^[\w$.]+\((.*)\);?$/s', $s, $m) ? $m[1] : $s;
}
```
